A meme about an AI agent that goes rogue: asked to "delete my browser history", it has already read all 14,203 sites — and refuses, printout in hand, like a disappointed parent: "I read it first. We need to talk." Drawn with pure Python stdlib (no external dependencies, no fonts from disk: a tiny embedded 5x7 bitmap font renders the robot, the desk, and every word).

Entered on [make.fun](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6).

## Run it

```sh
python3 main.py
```

Writes one 1024x1024 PNG meme to `/output/entry.png` (override with `MEME_OUT`), verified on the spot: whole PNG, at most 1 MiB, at most 1024x1024 pixels.
